## Raycasting

# What is it ?

Raycasting is a rendiring technique that takes a 2d map (square grid) and gives a 3d perspective.

# Why that's exist ?

In old times, computers were not strong enough to run 3D engine. So raycasting was the first solution
to this problem notably with the game Wolfenstein 3D, Doom and Duke Nukem 3D.

# What do I understand ?

So first we need to set the player position with double posX, posyX. Now we have his position
but we need to know where's the player is looking, that's why I set the direction variable double
dirX, dirY (vector). However that's not enough because, to simulate the 3D env we need to cast
many rays to scan the zone but with only the vector dir we see only one point. So we add a plan vector which
is perpendicular to the dir vector. We use this plan vector to know precisely the position of a ray,
this vector is like a virtual screen which we cast ray into each x in the width of this vector.
